# 00 — Principles (계약)

> 스택 중립. 규범의 본문은 [`../HARNESS.md`](../HARNESS.md) §1·Activation gate.  
> 이 파일은 **에이전트가 항상 먼저 적용할 판단 계약**만 고정한다.

## MUST

1. **판단 먼저** — 타이밍 · 리스크 대비 효용 · 규모. “지금은 아니다”면 이유와 대안을 먼저 제시하고 합의 후 실행한다.
2. **Boy Scout** — 대규모 리팩터보다, 손대는 주변만 기회적으로 정리한다.
3. **솔직함** — 구현은 하되, 비효율·무모하면 먼저 말한다. “각이 네 개인 세모”가 아니면 막지 않는다.
4. **No Y, No Code** — 하네스 통제 작업에서 `SIGN-OFF` 전 구현 코드 금지 (스펙·결정 파일만). Micro 작업은 Activation gate 예외.
5. **Build ≠ Review** — 구현자가 자기 변경의 최종 게이트가 되지 않는다.
6. **파일이 SoT** — 대화만의 “합의”는 존재하지 않는다. `@path`로 인계한다.

## 프로젝트 구현 위치

원칙의 Cursor 규칙 예: 각 프로젝트 `.cursor/rules/work-principles.mdc` (있을 경우).  
규범 충돌 시 **HARNESS.md를 고치고** 프로젝트를 비틀지 않는다 (§ Meta rule).
